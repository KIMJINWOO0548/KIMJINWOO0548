# 김진우 · SW / AI / 데이터

장비 신호를 읽는 Windows 작업대부터, 규칙과 근거를 검토하고 승인 결과를 복구하는 도구까지 만듭니다.

## 공개 제품과 프로젝트

| 프로젝트 | 직접 확인할 수 있는 흐름 | 실행 |
| --- | --- | --- |
| **Diffmere Free** | 두 파일과 폴더의 차이를 찾아 비교하고 검토하는 Windows 앱 | [Microsoft Store](https://apps.microsoft.com/detail/9nfx219xn2h4?hl=ko-KR&gl=KR) |
| **OpsPilot-X** | 권한과 문서 버전을 확인하고, 별도 검토자가 승인한 조치를 한글 PDF와 영수증으로 남깁니다. | [시연·소스](https://github.com/KIMJINWOO0548/OpsPilot) · [Windows ZIP](https://github.com/KIMJINWOO0548/OpsPilot/releases/latest) |
| **Aegis Insight** | 모듈과 태그를 선택해 현재 상태·추세·원시 이력을 보고, 필요한 신호를 읽기 전용 오버레이에 고정합니다. | [시연·소스](https://github.com/KIMJINWOO0548/Aegis) · [Windows ZIP](https://github.com/KIMJINWOO0548/Aegis/releases/latest) |
| **CaseProof Enterprise** | 합성 보험 규칙의 변경 전후를 평가하고 사례·근거·독립 승인 이력을 한 화면에서 확인합니다. | [시연·소스](https://github.com/KIMJINWOO0548/CaseProof_Enterprise) · [Windows ZIP](https://github.com/KIMJINWOO0548/CaseProof_Enterprise/releases/latest) |

세 Windows 포터블 프로젝트는 합성 자료로 실행 흐름을 확인할 수 있습니다.

## 실무 경험

**케이씨텍 인턴십**에서 장비 시계열을 분석하고 LSTM Autoencoder 기반 이상 탐지를 다뤘습니다. 장비 동작을 해석하는 경험은 Aegis에서 신호의 현재값·누락·이력을 구분하고 원시 근거를 남기는 설계로 이어졌습니다.
