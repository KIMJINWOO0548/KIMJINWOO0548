# 김진우 · SW / AI / 데이터

실시간 제어와 프로세스 간 통신(IPC), C++·C# 장비 소프트웨어를 다뤘습니다. 개인 프로젝트에서는 Windows 제품을 출시하고, 장비 신호의 이력과 규칙 평가·승인 근거를 검토하는 도구를 개발합니다.

## 실무 경험

- **페이브텍** · 실시간 제어 소프트웨어와 프로세스 간 통신(IPC)을 다뤘습니다.
- **케이씨텍** · C++ DLL과 C# WPF UI를 P/Invoke로 연결하는 장비 제어 소프트웨어를 다뤘습니다.
- **케이씨텍 인턴십** · 장비 시계열을 분석하고 LSTM Autoencoder 기반 이상 탐지를 다뤘습니다.

이 경험을 Aegis의 모듈별 신호 수집, 현재값과 이력의 구분, 원시 근거 보관 설계에 연결했습니다.
